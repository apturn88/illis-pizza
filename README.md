# Illi's Pizza

Marketing site for Illi's Pizza — Belmont, Calgary, Alberta.

> Pizza Worth Coming Home For.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 3

## Develop

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Pages

- `/` — landing
- `/about` — story
- `/contact` — visit, hours, message form (mock)

## Notes

This is a mockup. Address, phone, hours, and the contact form are placeholders.
